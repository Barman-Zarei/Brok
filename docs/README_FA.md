## بروک 🤖 — همراه دسکتاپ هوشمند و ایجنت کدنویسی با اولویت فارسی

<img src="brok.gif" width="140" alt="Brok"/>

بروک یک ربات کوچک روی دسکتاپ شماست (بدون قاب، همیشه روی صفحه، قابل جابه‌جایی) که **اول از همه فارسی** با شما گفتگو می‌کند و می‌تواند به‌عنوان **ایجنت کدنویسی با کنترل مجوز** روی پروژه‌های شما کار کند. این پروژه برگرفته از [myCat](https://github.com/yumiaura/myCat) است (فایل‌های NOTICE و LICENSE.txt را ببینید).

### قابلیت‌ها
- آواتار ربات با ۱۳ حالت (بیکار، شنونده، در حال فکر، تایپ، کدنویسی، سخنگو، خوشحال، گیج، خطا، موفق، خواب، اعلان…)
- گفتگو با **Claude**، **Ollama (محلی)** یا هر API سازگار با OpenAI؛ برچسب «هوش مصنوعی محلی/ابری» همیشه نمایش داده می‌شود
- **محیط کدنویسی**: فایل‌ها، ویرایشگر، چت، نمایش تغییرات (diff)، ترمینال، مشکلات، گیت؛ کد را انتخاب کنید و بگویید «توضیح بده / باگ را پیدا کن / بهینه کن / تست بنویس / تبدیل به Flutter»
- **ایمنی**: هر ابزار سطح ریسک دارد؛ ویرایش فایل ابتدا diff نشان می‌دهد؛ حذف، commit، push و دستورهای پرخطر همیشه تأیید می‌خواهند؛ دستورهای خطرناک مسدود می‌شوند
- رابط فارسی و راست‌به‌چپ، حالت آموزش، دیباگر هوشمند، گزارش سلامت پروژه، حافظه‌ی قابل مشاهده/ویرایش/حذف، حالت فقط‌محلی (آفلاین)

### نصب (پایتون ۳.۸ به بالا)
```bash
pip install .
brok                              # اجرای همراه دسکتاپ
export ANTHROPIC_API_KEY=...      # اختیاری برای Claude (یا Ollama محلی)
brok-agent doctor                 # بررسی اتصال
brok-agent --project . ask "این ارور یعنی چی؟"
```
